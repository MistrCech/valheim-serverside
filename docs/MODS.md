# The popular cheat and tweak mods, and what the anti-cheat sees of them

The table of the README's Anti-cheat section, moved here for the size of the README (Thunderstore takes at most 100,000 characters of it). "Caught" is not tested against the mod itself: it means the rule is tested with simulated players sending what the mod's code makes.

From the READMEs of 65 popular cheat and tweak mods on Thunderstore and the decompiled code of 29 of them (downloads in millions, October 2026; the table lists the ones that matter for a server whose players run unmodified games, about forty of the 65, and several of them exist under more than one name on Thunderstore, as forks and reuploads): what each can do that the game cannot, and what the server would see. The "basis" column says whether the row rests on the mod's decompiled code (read, not run) or only on its README. "Caught" is not tested against the mod itself -- it means the rule is tested with simulated players sending what the mod's code makes (see below).
